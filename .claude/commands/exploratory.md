# /exploratory

Create a session-based exploratory testing charter for a feature area.

Apply the `exploratory-testing-and-bug-reports` skill.

## Usage

Expects a feature area or area of concern as input (not a fixed test case list — exploratory testing is charter-driven, not scripted). Output is a charter: mission (what you're investigating and why), scope boundaries, a time-box, and the specific risks or questions the session should answer.

Any defects found during the session should be captured as reproducible bug reports (see `/bug-report`), not just noted informally.
